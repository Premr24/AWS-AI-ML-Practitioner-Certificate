### 2. AI-Assisted Data Analysis: Air Quality Trends
* **Description:** Used generative AI to perform exploratory data analysis on a 4,000+ row dataset of air quality metrics. Engineered prompts to extract temporal patterns (diurnal pollution cycles) and format the output into structured tables.
* **Skills:** Data Analysis, Prompt Engineering for Data, Data Validation.
* **Files Included:** Raw dataset, AI-generated summary CSV, and the final analytical report.
